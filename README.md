# Minigame 1
## Devlog
I would say that a good way to illustrate the relationship between Components, GameObjects, and Scenes would be to imagine Components as the organs (or perhaps more generally, attributes?) of GameObjects, as they each constitute/modify certain features of their respective GameObject. From there, GameObjects could be likened to animals/objects within a given environment, or Scene, as GameObjects are made to exist/interact with each other within a specific, defined context, that being the Scene, in a similar manner to how animals and plants and other various objects interact with each other in a specific environment.
